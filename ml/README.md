# ML Pipeline

This directory contains the machine learning pipeline for the IDR Navigation System.

## Structure
- `data/`: Local dataset storage
- `notebooks/`: Jupyter notebooks for analysis and experimentation
- `src/`: Reusable python modules for ingestion, cleaning, training, export
- `models/`: Trained model checkpoints and ONNX exports
- `configs/`: Pipeline configuration files
- `tests/`: Pytest tests for the ML pipeline
